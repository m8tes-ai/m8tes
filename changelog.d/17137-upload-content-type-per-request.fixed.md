- Two file uploads on one client, from two threads, no longer make each other fail. The client used to take the JSON `Content-Type` off its shared session for an upload and put it back afterwards, so one finished upload could put `application/json` onto another upload that was still being sent or retried, and the server rejected that upload. The header is now set on each request and never on the shared session. A `content-type` header you pass in lower case is also dropped from an upload, so the body keeps its multipart boundary.
